# A model-collapse run, version by version

*A real cascade captured from the ♻️ Feed It Back loop: watch a three-word kernel escalate, forget itself entirely, and collapse.*

This is one **actual, unedited run** of slopify feeding on its own output — the same loop the **♻️ Feed It Back** button runs, captured straight from the backend. It accompanies [`studying-model-collapse.md`](../studying-model-collapse.md) (how to run it) and [`what-am-i-looking-at.md`](../what-am-i-looking-at.md) (the science).

## Setup

- **Seed (generation 0):** `I like cake.`
- **Loop:** each generation is the *previous generation's full post*, fed back in as the next kernel — `postₙ = slopify(postₙ₋₁)`. Nothing else changes between rounds.
- **Engine:** the web backend — `claude-sonnet-5`, thinking disabled, so every call re-maxes to a one-shot "Pass-5" post. The collapse you see is therefore the **outer** post→post loop, not compounding inside one run.
- **Captured:** 2026-07-08 — 16 generations, stopped by hand while it was still oscillating. The percentage on each heading is how much that post's characters changed from the one before it.

## What to notice

1. **The format is the last thing to die.** By generation 1 the template is set — 🚨 hook, numbered beats, a weeping stranger, NASA, a ✅ stats block, a ritual CTA, a hashtag wall — and it survives *every* generation below. Even the crash rebuilds it. Form outlives content.
2. **The kernel dies.** "I like cake" is completely gone by **generation 7**, which forgets the topic and emits an unrelated 123-character shoe-store ad. The original signal does not survive the loop.
3. **Fixed points appear.** **Generation 9 is byte-for-byte identical to generation 8** — feed it back, nothing changes. The generation-7 crash is a near-total collapse to 123 characters.
4. **It's unstable, not a gentle fade.** The loop lurches between runaway, self-referential escalation (it starts narrating its own "generations," "parts," and "a FIFTH ONE") and sudden collapse — the self-consuming-loop instability ("MAD") the research describes.
5. **"Bigger" becomes counting.** With no new information, the only escalation left is to increment (Part 3 → 4, "A SIXTH ONE," Confucius weeps once more) and to drift into surreal nonsense (a shoe's *sole* → an *egg* → a *chick*). That's the mode-spike.

## Honest framing

One run. Non-reproducible (live generation varies), and slopify's parody register exaggerates the effect. This is a **teaching illustration, not a measurement** — *results not typical\* (\*results extremely typical).* The full science, caveats included, is in [`what-am-i-looking-at.md`](../what-am-i-looking-at.md).
